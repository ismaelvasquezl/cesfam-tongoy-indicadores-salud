El punto de partida

El dato existe.
Está enterrado.

Cada mes, cada dispositivo genera un REM Serie A con ~30 hojas. Multiplicado por tres centros y doce meses, la información de gestión queda repartida en cientos de celdas.

  • Revisar producción es abrir planilla por planilla, a mano.
  • Las alertas epidemiológicas aparecen tarde, cuando el mes ya cerró.
  • Comparar centros o meses exige rehacer el cálculo cada vez.
  • Un solo analista sostiene todo el proceso.

La idea

Que el REM se lea solo,
y muestre lo importante.

Se carga el archivo tal cual sale de DEIS. El sistema reconoce el dispositivo, el mes y el año, extrae los indicadores clave y arma un tablero navegable. Sin transcribir nada a mano.

Cómo funciona

Tres pasos, cada mes.

1

Cargar el REM

Se sube el archivo Serie A / P tal como se descarga. No se edita ni se renombra.

→
2

Extracción automática

Autodetecta DEIS, mes y año; lee ~30 hojas y arma la base de datos con caché para no repetir trabajo.

→
3

Dashboard

Un HTML autocontenido: producción, alertas, coberturas, programas y proyección — listo para revisar.

Robusto ante detalles reales del REM: identifica el dispositivo por celdas fiables (no por fórmulas rotas), maneja meses incompletos y evita que archivos de distinto año se pisen entre sí.
